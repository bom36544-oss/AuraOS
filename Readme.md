# AuraOS

Своя операционная система, написанная с нуля.
Не Linux, не Windows, не macOS — полностью своя.

## Технологии
- ASM (загрузчик)
- C (ядро)

## Что готово
- ✅ Aura Boot (загрузчик)
- ✅ Protected mode (32-бит)
- ✅ VGA вывод
- ⏳ Ядро на C (в работе)

## Архитектура
- x86 (пока 32-бит)
- BIOS (UEFI — позже)
- Своё ядро
- Своя ФС (AuraFAT — план)
- Свой GUI (Aura GUI — план)

## Фишки
- Кастомизация через JSON
- Своё расширение .aurapp
- Без серверов
- Полная свобода

## Сборка
```bash
cd boot
make
make run
